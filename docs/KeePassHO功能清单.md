# KeePassHO 功能清单（含具体操作路径）

> 依据 `entry/src/main/ets/` 源码整理。所有路径均为实际可操作点。
> 4 个根页面（由 `AppNavigation.ets` 管理）：`Index`（首页）/ `DatabaseView`（数据库）/ `TotpView`（TOTP）/ `Settings`（设置）。锁屏时会覆盖 `UnLockDatabase` 浮层。

---

## 一、首页（Index）

| 功能 | 操作路径 | 说明 |
|---|---|---|
| 打开数据库 | 首页 →「打开数据库」 | 进入「选择位置」选择存储方式与文件，随后进入密码解锁页 |
| 创建数据库 | 首页 →「创建数据库」 | 进入数据库创建页 |
| 最近打开 | 首页 →「最近打开文件」 | 进入最近打开列表 |
| 进入设置 | 首页右上角齿轮图标 | 切换到「设置」根页面 |
| 自动跳转最近文件 | 冷启动自动 | 若已预加载最近文件 → 自动进入解锁页；否则等待≤500ms 后加载最近一次文件 |

## 二、创建数据库（CreateDatabase）

路径：`首页 → 创建数据库`

| 功能 | 操作路径 | 说明 |
|---|---|---|
| 数据库名称 | 名称输入框 | 必填，自动补 `.kdbx` 后缀 |
| 设置密码 | 密码 + 确认密码 | 两次一致才允许创建，不一致报错 |
| 选择密钥文件 | 密钥文件名区域 → 选择位置(SAVE) | 选取已有 `.key` 文件作为密钥 |
| 新建密钥文件 | 密钥文件区「新建」 | 生成随机密钥文件并保存到所选位置 |
| 仅密钥文件模式 | 勾选「仅密钥文件」 | 隐藏密码框、密钥文件必填，无密码创建 |
| 创建 | 「创建」按钮 | 校验通过后 `Kdbx.create` → 选择保存位置 → 跳转密码解锁页 |

| 方式 | 操作路径 | 说明 |

| WebDAV | → WebDAV | 配置服务器/账号/密码后连接 → 文件列表 |
| S3 | → S3 | 填 endpoint/AK/SK 等 → 文件列表 |
| FTP/SFTP | → FTP | 填主机/协议/账号等 → 文件列表 |
| OneDrive | → OneDrive | OAuth2 授权登录 → 文件列表 |
| 华为云盘 | → 华为云盘 | OAuth2 授权（可选手动全库/应用文件目录） → 文件列表 |
| pCloud | （工厂中注释禁用，不可选） | 代码存在但未接线 |
| Google Drive | （StorageType 有定义，未注册） | 未接线 |

## 五、密码解锁页（Password）与锁屏（UnLockDatabase）

### 解锁页

| 功能 | 操作路径 | 说明 |
|---|---|---|
| 切换认证方式 | 顶部下拉 | 密码 / 密钥文件 / 密码+密钥文件 |
| 输入密码 | 密码框（眼睛切换明文） | 回车触发解锁 |
| 选/重选密钥文件 | 「密钥文件」按钮 → 选择位置 | 保留已输入密码 |
| 生物识别解锁 | 若已保存密码，进入自动尝试指纹/人脸 | 失败回退密码；页面有「用指纹/人脸解锁」链接 |
| 仅使用本地缓存 | 勾选「仅使用本地缓存」 | 仅远程有缓存时显示，只读不连服务器 |
| 更改数据库 | 底部「切换数据库」 | 重新进入选择位置 |
| 解锁 | 底部「解锁」 | Worker 加载 KDBX → 进入数据库视图 |
| 锁屏解锁浮层 | 手动/超时自动锁后出现 | 快速解锁 / 生物 / 关闭（见下） |

### 锁屏浮层（UnLockDatabase）
- **快速解锁**：输入子串密码（默认匹配 3 位），成功发 unlock 事件关浮层
- **指纹/人脸快速解锁**：浮层底部链接 → 生物识别
- **关闭数据库**：浮层底部「关闭」→ 关闭当前库

## 十一、TOTP / 一次性密码

### 支持的格式（兼容层按优先级解析）
| 格式 | 触发字段 |
|---|---|
| 标准 `otpauth://totp/`（含 Steam 编码） | `otpauth://totp/` 前缀 |
| KeePass 2 原生 TOTP | `TimeOtp-Secret` / `-Base32` / `-Hex` / `-Base64`、`TimeOtp-Length/Period/Algorithm` |
| KeeOtp | `otp` / `KeeOTP` 字段含 `key=` |
| KeeTrayTotp | `TOTP Seed` / `TOTP Settings` |

### 算法与参数
- HMAC：SHA1（默认）/ SHA256 / SHA512
- 令牌类型：RFC6238 / STEAM（固定 SHA1、5 位）/ 自定义
- 参数：位数默认 6、周期默认 30s、密钥 Base32；可随机生成

### 添加 / 编辑
| 功能 | 操作路径 | 说明 |
|---|---|---|
| 添加 TOTP | 条目编辑 → 「OTP」→ 对话框 | 令牌类型选择 → 密钥（手动 / 生成 / 扫码 `otpauth://`）→ 算法/位数/周期（序号）→ 名称/发行人（折叠）→ 实时预览 → 确认（存为保护字段 `otp`） |
| 编辑 TOTP | 编辑 `otp` 字段 | 就是一条自定义字段的 URL 值 |

### 展示
| 入口 | 说明 |
|---|---|
| 数据库列表行内 | 由「列表显示TOTP」控制，点击复制 |
| 条目详情字段 | 令牌组件由「条目显示TOTP」控制 |
| 聚合页 TotpView | 数据库 → 时钟 FAB；搜索 + 字母索引；点击复制 / 打开条目 |

#### 修改主密码（ChangePassword）
- 路径：`设置 → 数据库 → 修改主密码`
- 旧密码（仅密钥模式隐藏）、「仅使用密钥文件」勾选、新密码/确认、密钥文件选择/新建、「不使用密钥文件」
- 保存后清空记住的密码并回到解锁页重新认证

#### 密钥派生函数（SettingDatabaseKeyFunction）
- 算法：Argon2d / Argon2id / AES-KDF
- Argon2：加密次数(I)、内存MB(M，1–512)、并行度(P)
- AES-KDF：加密次数(R)
- 底部「保存」重算密钥（较重操作）

#### 数据库元数据（SettingDatabaseMeta）
- 数据库名称 / 描述 / 默认用户名
- 历史最大条数(0–999)、历史最大大小(MB)
- 启用回收站、启用压缩
- 保存或返回（有未保存提示）

#### 自定义图标（SettingCustomIcons）
- 标题「添加图标」→ 本地选择/网络下载 add
- 网格多选 → 底部「删除未使用图标」/「删除」

#### 默认保护字段（SettingDatabaseProtectedField）
- 标题/用户名/密码/URL/备注 开关，改动即保存

## 十三、导入 / 导出

### 导入
- 支持：CSV、KeePassXML、Bitwarden JSON
- 路径：`设置 → 数据库 → 导入数据库 → 选择格式 → 选择文件 → 完成`
- 明细：CSV 需含 Title 列，`/` 生成分组树；Bitwarden 处理登录/安全笔记/银行卡/身份凭证及自定义字段；XML（未加密 KDBX XML）

### 导出
- 支持：CSV、XML、KDBX（加密原生）、密钥文件（KeyFile）
- 路径：`设置 → 数据库 → 导出数据库 → 选择格式 → 选保存位置 → 完成`
- 文件名自动加 `_yyy一MM-dd` 日期后缀

## 十五、跨设备同步

路径：`设置 → 应用程序 → 数据同步`

- 基于华为分布式 KV 能力同步「设置项 + 最近打开文件」
- 请求 `ohos.permission.DISTRIBUTED_DATASYNC`（运行时）
- 冲突按单调版本号解决；「数据同步开关」本身不同步
