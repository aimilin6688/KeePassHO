# 子数据库使用指南

子数据库（Child Databases）功能允许在打开父数据库时自动打开其他数据库。字段约定与 KeeAutoExec 插件（PC）及 keepass2android（kp2a）兼容，并兼容 KeePassXC 的 `kdbx://` URL 写法（见 3.1）。KeePass 桌面版本身不内置该功能，安装 KeeAutoExec 插件后可用。

> **安全须知**：子数据库的主密码和文件位置存储在父数据库中。此功能允许与其他人共享您的一部分密码。请确认父数据库本身的保密强度满足需求。远端（云端）子数据库若属于凭据型存储（WebDAV/FTP/SFTP/S3），其连接用户名/密码也会存入父数据库条目（见第 3 节）。

---

## 1. 快速上手（本应用内完成）

### 1.1 添加子数据库

入口（任选其一，均需先解锁并进入父数据库）：

- **设置 → 数据库设置 → 子数据库管理**
- **数据库页顶部标题栏 ▾（数据库切换面板）→ 管理子数据库**
- **数据库页底部提示条 → 去配置**（父库存在未配置的 AutoOpen 条目时出现）

步骤：

1. 进入「子数据库」管理页，点右上角 **+**；
2. 选择来源：
   - **选择文件…**：从「最近文件」列表挑选一个 `.kdbx` 文件（**本地或云端均可**，需曾在本设备打开过），输入其主密码解锁；
   - **其他已打开的数据库**：直接选择列表中已打开的库（含已打开的云盘库）；
3. 解锁成功后，应用自动在父库根组下创建/复用 `AutoOpen` 组，并写入一条子库条目。

新添加的子库条目**仅对本设备启用**（IfDevice 白名单，保守默认），不影响其他设备行为。本地子库与父库同目录时，URL 自动写成 `{DB_DIR}{ENV_DIRSEP}相对路径`；云端子库则写入对应的 scheme URL，凭据型存储还会追加连接凭据字段（见 3.2）。

### 1.2 管理已有子库

在「子数据库」管理页，每行代表父库中的一个 AutoOpen 条目，长按/点击行尾菜单可：

| 操作 | 说明 |
|---|---|
| 在此设备上启用 / 禁用 | 改写条目 `IfDevice` 字段并保存父库 |
| 立即打开 | 手动打开该子库（自动打开失败后可重试） |
| 编辑 | 跳转普通条目编辑页修改任意字段 |
| 为此设备创建副本 | 克隆条目：原条目本设备置停用，副本仅本设备启用、标题追加设备型号——适合「多设备各用一套配置」 |
| 删除子数据库 | 确认后删除父库 AutoOpen 组中的该条目（进父库回收站）；仅解除自动打开关联，**不会删除子数据库文件本身** |

行内同时显示：标题、URL、本设备启用状态（是/否/未指定）、条目禁用态、已打开标记。本地与云端子库按存储类型显示对应存储图标。

### 1.3 自动打开行为

- 父库解锁成功后，应用按 `Priority` 升序在后台串行打开所有启用的子库（不抢占当前视图）；
- 打开结果可在**数据库切换面板**（标题栏 ▾）查看与切换；
- `SkipIfNotExists` / `SkipIfKeyFileNotExists` 命中时静默跳过；打开失败的子库可从切换面板或管理页手动重试；
- 云端子库打开失败时仅单条提示，不影响父库与其余子库（失败原因见 3.4）；
- 子库不会写入「最近文件」列表。

## 2. 与 PC 端互操作

### 2.1 在 KeePass 桌面端创建 AutoOpen 组

KeePass 桌面版（2.x）本身不内置 AutoOpen，需安装 [KeeAutoExec](https://keepass.info/help/kb/autopen_db.html) 插件（未安装时 AutoOpen 组只是普通数据，无副作用）。在数据库**根组**下创建名为 `AutoOpen` 的组（大小写不敏感），组内每条普通条目描述一个要自动打开的数据库：

| 字段 | 语义 |
|---|---|
| Title | 显示名（任意） |
| URL | 子库路径，支持 `{DB_DIR}`（父库所在目录）与 `{ENV_DIRSEP}`（路径分隔符）占位符 |
| Password | 子库主密码 |
| UserName | 子库密钥文件路径（有密钥文件时填写，同样支持占位符） |

> **`{DB_DIR}` 写法建议**：父子库放在同一目录时，推荐把 URL 写成 `{DB_DIR}{ENV_DIRSEP}child.kdbx`，这样整组文件移动目录或换设备后无需修改条目。本应用内添加子库时会自动生成这种相对写法。
> **KeePassXC 注意**：KeePassXC 不支持 `{ENV_DIRSEP}` 占位符（按字面量处理会导致找不到文件）。若父库也会在 KeePassXC 中使用，请改写含字面分隔符的 `{DB_DIR}/child.kdbx`（KeePassXC、本应用、kp2a、KeeAutoExec 均可识别）。

由桌面端创建的条目在未写 `IfDevice` 字段时，本应用按「未指定」处理——默认自动打开，同时数据库页底部会出现提示条，引导您显式指定本设备是否使用。

### 2.2 KeeAutoExec 字段扩展

本应用兼容 [KeeAutoExec](https://keepass.info/help/kb/autopen_db.html) 插件（PC）的字段扩展（同为 kp2a 采用）：

| 字段 | 取值 | 说明 |
|---|---|---|
| Enabled | true / false | 覆盖默认启用判定（默认：条目过期则禁用，否则启用） |
| Visible | true / false | 条目可见性（保留字段，本应用不依赖） |
| Priority | 整数 | 数值越小越先打开（默认按扫描顺序） |
| IfDevice | 设备 CSV | 设备过滤，见下节 |
| SkipIfNotExists | true / false | 子库文件不存在时静默跳过（不报错；远端子库恒视为存在，见 3.4） |
| SkipIfKeyFileNotExists | true / false | 密钥文件不存在时静默跳过 |
| IocUserName | 文本 | 远端子库连接用户名（WebDAV/FTP/SFTP 登录名；S3 为 AccessKeyId），见第 3 节 |
| IocPassword | 文本 | 远端子库连接密码（WebDAV/FTP/SFTP 登录密码；S3 为 SecretAccessKey）；应用内写入时受 KDBX 内存保护 |

### 2.3 IfDevice 设备过滤

`IfDevice` 字段填写设备标识 CSV，逗号分隔：

- `DeviceA` —— 仅在 DeviceA 上启用（白名单，未列出设备一律禁用）；
- `!DeviceA` —— 除 DeviceA 外都启用；
- `DeviceA,DeviceB` —— 在 DeviceA 或 DeviceB 上启用；
- 空字段 —— 未指定：所有设备默认启用（应用会提示您显式配置）。

本应用的设备标识格式为 `厂商 型号 (设备本地ID)`，可在管理页对本设备执行「启用/禁用」自动写入正确的标识，无需手工查找。

## 3. 远端（云端）子数据库

子数据库不限于本地文件：条目 `URL` 写成带 scheme 的地址即可指向云端数据库，父库解锁后会同样自动打开。

### 3.1 支持的存储与 URL 写法

| 存储 | 条目 URL 写法 | 连接凭据存储位置 |
|---|---|---|
| 本地文件 | 裸路径 / `file://` / `kdbx://`（KeePassXC 写法）/ `{DB_DIR}` 相对路径 | — |
| WebDAV | `https://host[:port]/路径` 或 `http://...`（`webdav://`、`webdavs://` 自动按 https 处理） | 父库条目 `IocUserName` / `IocPassword` |
| FTP | `ftp://host[:port]/远端路径`（默认端口 21 可省略） | 同上 |
| SFTP | `sftp://host[:port]/远端路径`（默认端口 22 可省略） | 同上 |
| S3 | `s3://endpoint/bucket/对象键` | `IocUserName`=AccessKeyId、`IocPassword`=SecretAccessKey |
| OneDrive | `onedrive://远端路径` | 本设备（需先手动打开过一次） |
| 华为云盘 | `huawei-drive://远端路径` | 本设备（同上） |
| 百度网盘 | `baidu://远端路径` | 本设备（同上） |

> pCloud 存储当前版本暂未开放，暂不能作为子数据库。

> `kdbx://` 为 KeePassXC 2.8 的私有 URL 前缀：本应用与 KeePassXC 一样按「剥离前缀后按本地路径」处理（相对路径按父库目录解析）；KeeAutoExec（PC）与 kp2a 不识别该写法，跨端共用父库时请写普通路径。

### 3.2 凭据型存储（WebDAV / FTP / SFTP / S3）

- 在应用内添加这几类子库时，除写入 scheme URL 外，还会把连接用户名/密码写入条目的 `IocUserName` / `IocPassword` 自定义字符串（`IocPassword` 受内存保护），字段与 KeeAutoExec（PC）同名兼容；
- S3 另有两个可选自定义字符串（本应用扩展）：`S3Region`（region 非 us-east-1 时写入）与 `S3PathStyle`（`True` 时写入）；
- 手写或编辑条目时请确保 `IocUserName` 已填写，否则自动打开失败并提示「缺少连接凭据」。

### 3.3 OAuth 型云盘（OneDrive / 华为云盘 / 百度网盘）

- 授权令牌**不写入 .kdbx**（避免随数据库分发），只保留在本设备「最近文件」的加密配置中；条目仅存路径；
- 在新设备上首次自动打开时，若本设备从未打开过该云端文件，会失败并提示「该云端子数据库尚未在本设备打开过，请先手动打开一次后重试」——手动正常打开一次后即可自动打开。

### 3.4 行为差异与失败提示

- `SkipIfNotExists` 仅对本地子库检查文件存在性，远端子库一律视为存在（避免逐个探测远端）；
- 远端不可达、凭据失效时，自动打开仅单条提示且不会反复重试，父库与其余子库不受影响；可在切换面板或管理页手动重试；
- 子库打开后与本地子库完全同权：可切换、可保存、可刷新。

## 4. 常见问题

**Q：可以把云端数据库添加为子数据库吗？**
A：可以。WebDAV、FTP/SFTP、S3 以及 OneDrive、华为云盘、百度网盘均可作为子数据库：在「其他已打开的数据库」中直接添加，或先正常打开一次使其进入「最近文件」后经「选择文件…」添加。凭据型存储的连接凭据会随条目存入父库（见 3.2）；OAuth 型云盘的令牌只保留在本设备（见 3.3）。

**Q：子库主密码存在哪里？安全吗？**
A：存储在父库 AutoOpen 条目的 Password 字段（受 KDBX 内存保护，通常为 ProtectedValue 加密存储）。任何能解锁父库的人都可以看到子库密码——这正是「共享部分密码」功能的设计前提，请酌情使用。凭据型远端子库的连接密码（`IocPassword`）同样存于父库条目，敏感级别与主密码相同。

**Q：桌面端创建的条目会自动打开吗？**
A：会。未写 `IfDevice` 的条目按「未指定=启用」处理；若您不希望本设备打开，可在管理页对本设备执行「禁用」。

**Q：KeePassXC 里配置的条目（URL 以 `kdbx://` 开头）能用吗？**
A：可以。本应用按 KeePassXC 约定剥离 `kdbx://` 前缀后按本地路径处理，相对路径按父库目录解析。注意 KeePassXC 不支持 `{ENV_DIRSEP}` 占位符，跨端通用写法见 2.1 的写法建议。

**Q：自动打开失败怎么办？**
A：检查子库文件是否存在（或为条目添加 `SkipIfNotExists=true`）、密码是否变更、设备是否被 `IfDevice` 排除；远端子库还需检查连接凭据是否齐全（凭据型）或是否已在本设备手动打开过一次（OAuth 型，见第 3 节）。修复后可在切换面板或管理页手动打开。
